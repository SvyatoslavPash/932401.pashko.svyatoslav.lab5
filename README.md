# Лабораторная работа №5 — DOM и взаимодействие с элементами страницы

**Вариант 16.** Тема: «Предприниматель и стартапер» — список идей с метриками.

---

## 📋 Цель работы

Научиться манипулировать DOM-деревом: находить элементы, изменять содержимое, атрибуты и стили, добавлять/удалять элементы, а также сохранять состояние страницы между перезагрузками через `localStorage`.

---

## 🎯 Реализованный функционал

| Пункт ТЗ | Реализация |
|---|---|
| Поиск элементов | `getElementById`, `querySelector`, `querySelectorAll` |
| Изменение текста | `textContent`, `createTextNode` |
| Изменение атрибутов | `setAttribute('data-id', …)` |
| Изменение классов | `classList.toggle('dark-theme')` |
| Добавление элементов | `createElement` + `appendChild` |
| Удаление элементов | `ideas.pop()` и `Array.filter` |
| Переключение темы | кнопка `#theme-toggle`, класс `dark-theme` на `<body>` |
| Скрытие/показ блока идей | кнопка `#toggle-ideas`, `style.display` |
| Проверка существования элемента | функция `checkExists(el, name)` с `console.error` |
| Сохранение состояния | `localStorage` — ключи `startup_ideas`, `startup_theme` |
| Восстановление при загрузке | `loadIdeasFromStorage()` + `loadTheme()` в `DOMContentLoaded` |

### Логика варианта

- **Карточка идеи** содержит: название, целевую аудиторию, метрику (MAU) и кнопку «Удалить».
- **«Добавить идею»** — форма с тремя полями, при отправке создаётся новая карточка.
- **«Удалить последнюю»** — убирает последнюю идею из списка.
- **Переключение темы** — светлая ↔ тёмная, состояние сохраняется.
- **Скрытие идей** — сворачивает контейнер с карточками, кнопка меняет текст.
